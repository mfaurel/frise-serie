# S01: TypeScript types and static data files

**Goal:** Create TypeScript type definitions (Show, Era, HistoricalEvent, Genre, Region, Platform) matching the PRD/architecture data model, and populate static data files (shows.ts, eras.ts, events.ts) with real historical TV series data — ~50 shows across 6+ eras, 20+ historical events.
**Demo:** Import shows.ts and log all 50 shows with correct types — no compile errors

## Must-Haves

- types/index.ts exports Show, Era, HistoricalEvent, Genre, Region, Platform types matching ARCHITECTURE.md data model
- data/shows.ts exports a typed array of ~50 real historical TV series with correct Show types
- data/eras.ts exports 6+ era definitions with year ranges, color palettes, and descriptions
- data/events.ts exports 20+ historical event markers with years
- All files compile with zero TypeScript errors (npx tsc --noEmit)
- Import shows.ts and log all shows with correct types — no compile errors
- Vitest passes on type-checking and data integrity assertions

## Proof Level

- This slice proves: contract — TypeScript compilation and Vitest data integrity tests prove the types and data are correct without requiring runtime rendering
