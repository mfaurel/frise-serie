# S02: yearToPixel density algorithm — UAT

**Milestone:** M001
**Written:** 2026-07-26T20:33:47.122Z

## UAT Type

- UAT mode: artifact-driven
- Why this mode is sufficient: This slice implements pure, synchronous library functions (lib/constants.ts, lib/density.ts, lib/yearToPixel.ts, lib/pixelToYear.ts) with no UI, no route, and no runtime consumer yet (per D001, wiring into components is deferred to a later UI slice). There is nothing browser-observable to navigate to or screenshot; the entire contract is provable via TypeScript compilation and Vitest assertions against the real data files.

## Preconditions

- Repo dependencies installed (`npm install` already done in this environment)
- No dev server required — this UAT does not touch the browser

## Smoke Test

Run `npx vitest run tests/year-to-pixel.test.ts` — expect `25 tests` all passing, exit code 0.

## Test Cases

### 1. Vikings/793 demo case (roadmap acceptance)

1. Build zones with `buildDensityZones(shows, eras, totalWidth)` using real `data/shows.ts` and `data/eras.ts`.
2. Call `yearToPixel(793, zones)`.
3. **Expected:** Returns a pixel position inside the "antiquity"/medieval-adjacent era zone corresponding to the Vikings show's narrativeYearStart; `pixelToYear(yearToPixel(793, zones), zones) === 793` exactly.

### 2. BC date round-trip

1. Call `yearToPixel(-73, zones)` (73 BC) and `yearToPixel(-3000, zones)`.
2. Feed each result back into `pixelToYear`.
3. **Expected:** Both round-trip to exactly `-73` and `-3000`; no off-by-one from the no-year-zero conversion.

### 3. Density cap enforcement

1. Inspect every zone returned by `buildDensityZones` for the real dataset.
2. **Expected:** Every zone's effective px/year falls within `[MIN_PX_PER_YEAR, MAX_PX_PER_YEAR]` from `lib/constants.ts`.

## Edge Cases

### Era boundary continuity

1. For each pair of adjacent zones, compare the end pixel of zone N to the start pixel of zone N+1.
2. **Expected:** They are contiguous (no gap or overlap) even though px/year differs between zones.

### Out-of-range year

1. Call `yearToPixel` with a year far outside any zone's range (e.g. year 9999).
2. **Expected:** Clamps to the nearest boundary zone rather than throwing; only an empty `zones` array throws.

## Failure Signals

- Any of the 25 Vitest assertions failing
- `npx tsc --noEmit` reporting type errors in lib/ or tests/
- A round-trip (`pixelToYear(yearToPixel(y, zones), zones) !== y`) failing for any sampled year
