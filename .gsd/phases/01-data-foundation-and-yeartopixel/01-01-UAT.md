## UAT Type

- UAT mode: artifact-driven

Proof Level for this slice is explicitly "contract": TypeScript compilation plus Vitest data-integrity assertions.

## Preconditions

- Dependencies installed (`npm install`) in the project root `C:/workspace/frise-serie`.
- No dev server required — this slice has no runtime/browser component.

## Smoke Test

Run `npx tsc --noEmit` from the project root — expect exit code 0 with no TypeScript errors.

## Test Cases

### 1. TypeScript compilation

1. Run `npx tsc --noEmit`.
2. **Expected:** Exit code 0, zero errors, across types/index.ts, data/shows.ts, data/eras.ts, data/events.ts, and tests/data-integrity.test.ts under strict mode.

### 2. Data integrity test suite

1. Run `npx vitest run`.
2. **Expected:** tests/data-integrity.test.ts reports 25/25 tests passed, covering quantity thresholds (~50 shows, 6+ eras, 20+ events), referential integrity (every event's eraId resolves to a real era), BC-date handling, era contiguity, and malformed/negative-input guards.

## Edge Cases

### BC dates

1. Inspect data/shows.ts or data/events.ts entries with negative year values.
2. **Expected:** Negative years are accepted by the types and validated correctly by the BC-date tests in tests/data-integrity.test.ts.

### Era contiguity

1. Sort data/eras.ts by yearStart.
2. **Expected:** Each era's yearStart equals the previous era's yearEnd, with no gaps — enforced by a dedicated test.

### Referential integrity

1. Cross-reference every eraId in data/events.ts against the ids in data/eras.ts.
2. **Expected:** All eraIds resolve to an existing era; the test suite fails loudly if any event references a nonexistent era.

## Failure Signals

- `npx tsc --noEmit` reports type errors (broken contract between types/index.ts and data/*.ts).
- `npx vitest run` reports failures in tests/data-integrity.test.ts (wrong show/era/event counts, broken eraId references, BC-date mishandling, era gaps).

## Not Proven By This UAT

- No yearToPixel/pixelToYear mapping — that's S02.
- No year display formatting (FR/EN, BC notation) — that's S03.
- No performance or accessibility characteristics — there's no UI yet to measure.
