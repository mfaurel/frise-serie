# S01: ShowCard component with star-node glow and positioning — UAT

**Milestone:** M003
**Written:** 2026-07-30T20:42:32.456Z

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: The Playwright spec (`e2e/timeline-s01.spec.ts`) exercises all four Must-Have acceptance criteria against a live dev-server render. The spec runs headlessly in Chromium and exits 0, making it repeatable and CI-safe. No additional manual browser steps are needed; the spec's computed-style assertions cover the era-colored glow requirement that would otherwise require DevTools inspection.

## Preconditions

- Dev server: `npm run dev` → `http://localhost:3000` (auto-started by `playwright.config.ts` `webServer` block; `reuseExistingServer: true` for local runs)
- `data/shows.ts` must export at least one show with a valid `narrativeYearStart` and matching era in `data/eras.ts`
- `lib/yearToPixel.ts` and `data/density.ts` must be importable without errors

## Smoke Test

```
npx playwright test e2e/timeline-s01.spec.ts
```
Expect: `4 passed` with exit code 0.

## Test Cases

### 1. Show cards are present in the parallax-cards layer

1. Navigate to `http://localhost:3000`
2. Locate `[data-testid="parallax-cards"] [data-testid="show-card"]`
3. **Expected:** count ≥ 1

### 2. First show card is visible with year content

1. Navigate to `http://localhost:3000`
2. Locate the first `[data-testid="show-card"]`
3. Assert it is visible; assert its text matches `/\d{4}/`
4. **Expected:** visible, text contains a 4-digit year (broadcast range)

### 3. Card wrapper is positioned by yearToPixel

1. Navigate to `http://localhost:3000`
2. Locate the first direct child `div` of `[data-testid="parallax-cards"]`
3. Read `element.style.left` via `evaluate()`
4. **Expected:** `parseFloat(left) > 0` — Spartacus (narrativeYearStart: -73) maps to a positive pixel offset in the Antiquity density zone, not to pixel 0

### 4. Star-node glow has era-colored box-shadow

1. Navigate to `http://localhost:3000`
2. Locate the first direct child `div` of `[data-testid="show-card"]` (the star-node element)
3. Read `window.getComputedStyle(el).boxShadow`
4. **Expected:** non-empty string, not `'none'` — confirms era color is applied as radial glow

## Edge Cases

### Broken poster URL degrades to grey SVG placeholder

1. Temporarily replace a show's `posterUrl` with an unreachable URL
2. **Expected:** The card renders a grey 80×112 SVG placeholder (data-URI) — no broken-image icon, no network error in the Network panel

### Show with no matching era falls back to eras[0]

1. A show whose `narrativeYearStart` falls outside all era ranges (edge of timeline)
2. **Expected:** The card renders with the first era's color palette as glow color; no crash or missing glow

## Failure Signals

- Playwright exits non-zero → card presence, positioning, or glow is broken
- `count === 0` for `[data-testid="show-card"]` → TimelineContainer failed to mount ShowCard or shows array is empty
- `left === 0` for all wrappers → yearToPixel returning 0 or style.left not being set
- `boxShadow === '' || boxShadow === 'none'` → era color lookup failed or box-shadow CSS not applied

## Not Proven By This UAT

- Swim-lane collision avoidance (deferred to S02)
- Narrative span bars or constellation lines (deferred to S03)
- Responsive layout / mobile viewport behavior
- Poster image actual load from real CDN URLs (only fallback path is exercised by this spec)
- Performance with a large shows dataset (current data/shows.ts has a small fixture set)

## Notes for Tester

- The dev server starts automatically via `playwright.config.ts`; no manual `npm run dev` is needed before running the spec.
- Test 3 relies on Spartacus (`narrativeYearStart: -73`) being the first show in `data/shows.ts` output order. If show ordering changes, the test may need a more specific selector.
- Era glow color is inspectable in DevTools: select the first child `div` of any `[data-testid="show-card"]` and check Computed → box-shadow.
