## UAT Type

- UAT mode: runtime-executable

Unit tests verify the algorithmic contract in isolation. Together they satisfy the Integration proof level stated in the slice plan.

- Dev server running: `npm run dev` → http://localhost:3000
- Playwright installed: `npx playwright install chromium`

## Edge Cases

### All shows non-overlapping (sparse era)

- computeSwimLaneLayout assigns all shows to lane 0 (top = 120px).
- **Expected:** Unit test case 2 confirms this; cards all render in a single row.

### Dense era with 3+ collisions requiring lane reuse

- Three overlapping shows: lane 0, lane 1, then lane 0 reused after the first show's right edge clears.
- **Expected:** Unit test case 4 confirms greedy first-fit reuse behavior.

## Failure Signals

- All card wrappers share the same top CSS value in the browser → swim-lane engine not wired or computeSwimLaneLayout returning lane 0 for all
- `npx playwright test e2e/timeline-s02.spec.ts` exits non-zero → regression in TimelineContainer wiring
- `npm test tests/swim-lane.test.ts` exits non-zero → algorithmic regression in computeSwimLaneLayout

## Not Proven By This UAT

- Narrative span bars or constellation lines (S03 scope)
- Behavior with more than ~8 shows in a single dense pixel cluster (not present in current data/shows.ts)
- Mobile/responsive viewport behavior (no viewport-resize tests)
- Pixel-exact visual regression (no screenshot diffing)

## Notes for Tester

gsd_exec bash runtime is unavailable on the Windows dev host — use `node` runtime with child_process or run commands directly in PowerShell. All Playwright tests run against the Chromium browser installed via `npx playwright install chromium`. The dev server must be running before Playwright executes.
