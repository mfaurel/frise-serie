# S02: Swim-lane layout engine

**Goal:** Implement a deterministic swim-lane layout engine that assigns show cards to non-overlapping horizontal rows so dense eras (e.g., Antiquity with Spartacus at -73 and Rome at -52) never render overlapping cards, while sparse eras keep cards on lane 0.
**Demo:** Cards in dense eras arrange in swim lanes without overlap. Sparse eras center cards.
