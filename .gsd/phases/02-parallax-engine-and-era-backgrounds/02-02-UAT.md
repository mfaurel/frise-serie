# S02: Horizontal scroll container with yearToPixel width — UAT

**Milestone:** M002
**Written:** 2026-07-27T20:13:45.253Z

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: The three slice acceptance criteria (scroll container visible, inner div offsetWidth > 10000, year label present) are fully covered by `e2e/timeline-s02.spec.ts` which runs headless Chromium via Playwright — no manual browser steps required.

## Preconditions

- `npm install` has been run (node_modules present, Playwright browsers installed via `npx playwright install`)
- Dev server not required for Playwright test execution (static HTML served via Playwright's own server or Next.js is started by the spec's `webServer` config if present)
- TypeScript compilation passes: `npm run typecheck` exits 0

## Smoke Test

Run `npx playwright test e2e/timeline-s02.spec.ts --reporter=line` — all 3 tests should pass in under 10 seconds.

## Test Cases

### 1. Scroll container is rendered

1. Run `npx playwright test e2e/timeline-s02.spec.ts`
2. **Expected:** `[data-testid="timeline-scroll"]` is visible in the DOM

### 2. Inner div pixel width matches density-zone total

1. Run `npx playwright test e2e/timeline-s02.spec.ts`
2. **Expected:** `document.querySelector('[data-testid="timeline-inner"]').offsetWidth` is greater than 10000

### 3. At least one year label is present

1. Run `npx playwright test e2e/timeline-s02.spec.ts`
2. **Expected:** At least one `[data-testid="year-label"]` element is visible in the scroll container

## Edge Cases

### Typecheck clean

1. Run `npm run typecheck`
2. **Expected:** Exit 0, zero diagnostics — confirms Server Component wiring is type-safe

## Failure Signals

- Any Playwright test failure: inspect `playwright-report/` for screenshot and trace
- `npm run typecheck` non-zero exit: TypeScript error in `app/components/TimelineContainer.tsx`, `app/page.tsx`, or imported lib files

## Not Proven By This UAT

- Visual correctness of label positions under different viewport widths
- S03 parallax layers — deferred to next slice
- `e2e/smoke.spec.ts` heading assertion (out of scope; that spec expects a removed heading)
