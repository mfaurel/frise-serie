## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: All parallax behavior is covered by e2e/timeline-s03.spec.ts — 5 assertions verify layer presence, era-bg count, and scroll-driven transform. Playwright runs against the live Next.js dev server. CI is configured with workers=1 and retries=2, ensuring reliable execution.

## Preconditions

- Dev server running: `npm run dev` → `http://localhost:3000` (Playwright config webServer automates this)
- npm dependencies and Playwright browsers installed
- Run with `--workers=1` locally to avoid hydration-timing flakiness in the scroll transform test

## Smoke Test

`npx playwright test e2e/timeline-s03.spec.ts --workers=1 --reporter=line` — all 5 tests pass in under 15s.

## Test Cases

### 1. Three parallax layers present in the DOM

1. Navigate to `http://localhost:3000/`
2. Assert `[data-testid="parallax-bg"]` is visible
3. Assert `[data-testid="parallax-axis"]` is visible
4. Assert `[data-testid="parallax-cards"]` is visible
5. **Expected:** All three elements visible — 3 of 3 assertions pass

### 2. Era backgrounds — 9 distinct gradient elements

1. Navigate to `http://localhost:3000/`
2. Count `[data-testid="era-bg"]` elements
3. **Expected:** Exactly 9 elements, each styled with `linear-gradient(to right, ...)` derived from the era's colorPalette

### 3. Scroll drives parallax-bg transform at 0.7× offset

1. Navigate to `http://localhost:3000/`
2. Set `[data-testid="timeline-scroll"].scrollLeft = 500` and dispatch native scroll event
3. Read `[data-testid="parallax-bg"].style.transform`
4. **Expected:** `translateX(350px)` — 500 × 0.7 = 350, yielding 0.3× effective visible speed

### 4. S02 regression — all prior assertions still pass

1. Run `npx playwright test e2e/timeline-s02.spec.ts --workers=1 --reporter=line`
2. **Expected:** 3 tests pass (timeline-scroll visible, timeline-inner width >10000px, year-label visible)

## Failure Signals

- `Received: ""` for the transform value → React hydration didn't complete before scroll event; run `--workers=1` to confirm
- era-bg count ≠ 9 → eras data changed or yearToPixel regression
- Any layer visibility test failing → regression in TimelineContainer JSX structure

## Notes for Tester

The scroll transform test dispatches a native `Event('scroll')` directly on the scroll container. React attaches `onScroll` directly to the element (not delegated) so it fires synchronously. The test passes reliably in CI (workers=1, retries=2) and in isolation but is flaky under 7+ local workers due to React hydration timing. Run with `--workers=1` for reliable local execution. A `waitForLoadState('networkidle')` before the scroll dispatch would eliminate this; deferred to M003 cleanup.
