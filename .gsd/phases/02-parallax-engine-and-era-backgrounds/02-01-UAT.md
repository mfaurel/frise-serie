# S01: Next.js project scaffold with App Router and static export — UAT

**Milestone:** M002
**Written:** 2026-07-27T15:37:47.411Z

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: playwright.config.ts uses a webServer block to auto-start `npm run dev` at localhost:3000; `npx playwright test e2e/smoke.spec.ts` covers both the live dev-server render path and the document metadata without manual browser interaction.

## Preconditions

1. `npm install` has been run and node_modules are present.
2. Playwright browser binaries installed: `npx playwright install chromium`.
3. No other process occupying port 3000 (playwright.config.ts auto-starts dev server; set `reuseExistingServer: true` locally if a dev server is already running).
4. `out/index.html` is present — run `npm run build` if it has been cleaned.

## Smoke Test

Run `npx playwright test e2e/smoke.spec.ts`. The test auto-starts the dev server, navigates to http://localhost:3000, asserts page title is "Frise Série" and h1 heading is visible. Exit 0 = slice is alive.

## Test Cases

### 1. Static export artifact check

1. Run `npm run build`.
2. Inspect `out/` directory.
3. **Expected:** `out/index.html` present and non-empty. Directory also contains `_next/` static assets, `404.html`, and `index.txt`.

### 2. Playwright smoke test — dev server render

1. Ensure Playwright browser binaries are installed (`npx playwright install chromium`).
2. Run `npx playwright test e2e/smoke.spec.ts`.
3. **Expected:** Playwright auto-starts dev server, navigates to `/`, asserts page title "Frise Série" and h1 heading visible. Test exits 0 with 1 passed.

### 3. TypeScript type-check

1. Run `npm run typecheck`.
2. **Expected:** tsc --noEmit exits 0 with no diagnostic output.

## Edge Cases

### CI environment — fresh dev server required

1. Set `CI=true` in environment.
2. Run `npx playwright test e2e/smoke.spec.ts`.
3. **Expected:** `reuseExistingServer: false` in CI mode, so Playwright always starts a fresh dev server. Test passes.

### Missing Playwright browser binaries

1. Skip `npx playwright install`.
2. Run `npx playwright test e2e/smoke.spec.ts`.
3. **Expected:** Playwright exits with error naming the missing browser executable and instructions to run `npx playwright install`. This is expected first-run setup, not a code defect.

## Failure Signals

- `out/index.html` absent after `npm run build`: static export misconfigured — verify `next.config.ts` contains `output: 'export'`.
- TypeScript errors on `npm run typecheck`: type regressions in scaffold — read tsc output for file/line details.
- Playwright exits non-zero with "page not found" or title mismatch: dev server failed to start or app/page.tsx heading changed — check `npm run dev` console output.

## Not Proven By This UAT

- Parallax engine behavior (S02, S03).
- Horizontal scroll and yearToPixel layout (S02).
- Era nebula gradient backgrounds (S03).
- Production CDN deployment or build artifact serving via static file server.

## Notes for Tester

The webServer block in playwright.config.ts auto-starts `npm run dev` — no manual server startup needed. First-time runners need `npx playwright install chromium`. The `out/` directory is already built; re-run `npm run build` only if scaffold files have changed since the last build.
